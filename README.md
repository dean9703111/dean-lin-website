# 林鼎淵 (Dean Lin) 個人形象網站

## 📋 專案介紹

這是一個為講師林鼎淵量身打造的專業個人形象網站。網站採用純前端技術開發，無需後端伺服器即可獨立運行，具備高度的設計感與互動性。

## 🎯 網站特色

### 設計特點
- **現代化設計**：採用藍色系專業配色，展現講師的權威感與可信度
- **響應式設計**：完美適配桌面、平板與手機等各種裝置
- **高效能優化**：輕量級前端架構，快速載入與流暢互動
- **視覺層次**：清晰的資訊架構與視覺引導

### 功能模組
1. **導航欄** - 粘性導航，快速跳轉各區塊
2. **Hero Section** - 吸睛的首頁主視覺與行動呼籲
3. **關於我** - 講師背景與自媒體連結
4. **擅長領域** - 三大核心專業領域展示
5. **個人成就** - 數據化成就、暢銷書籍、媒體專欄、授課現場
6. **課程資訊** - 兩門課程的完整介紹與大綱
7. **報價標準** - 透明的收費資訊
8. **聯繫方式** - 多種聯絡管道與合作流程
9. **頁腳** - 快速連結與社交媒體

## 🚀 快速開始

### 方式一：本地開啟（推薦）
1. 下載或複製整個 `dean-lin-website` 資料夾
2. 使用任何現代瀏覽器打開 `index.html` 檔案
3. 無需任何伺服器或依賴，直接即可查看

### 方式二：使用本地伺服器
```bash
# 使用 Python 3
python3 -m http.server 8000

# 使用 Python 2
python -m SimpleHTTPServer 8000

# 使用 Node.js (需先安裝 http-server)
npx http-server
```

然後在瀏覽器中打開 `http://localhost:8000`

### 方式三：部署到線上
- **GitHub Pages**：上傳到 GitHub 倉庫，啟用 Pages 功能
- **Netlify**：拖放資料夾到 Netlify，自動部署
- **Vercel**：連接 GitHub 倉庫，自動部署
- **傳統虛擬主機**：上傳所有檔案到伺服器

## 🎨 設計系統

### 色彩方案
- **主色 (Primary)**：`#1e3a8a` - 深藍色，代表專業與信任
- **主色淺色**：`#3b82f6` - 淺藍色，用於按鈕與連結
- **強調色 (Accent)**：`#0ea5e9` - 天藍色，用於突顯重點
- **文字色**：`#1f2937` - 深灰色，易於閱讀
- **背景色**：`#f9fafb` - 淺灰色，減少眼睛疲勞

### 排版
- **字體**：Segoe UI, Tahoma, Geneva, Verdana, Microsoft YaHei
- **標題大小**：H1 (3.5rem) → H6 (1rem)
- **行高**：1.6 - 1.8，確保可讀性

### 間距與佈局
- **容器寬度**：1200px（最大寬度）
- **內邊距**：2rem（桌面）、1rem（行動裝置）
- **卡片間距**：2rem
- **圓角**：0.5rem - 1rem

## ✨ 互動效果

### 已實現的互動
1. **平滑捲動** - 點擊導航連結時平滑捲動到對應區塊
2. **粘性導航** - 導航欄隨著捲動改變陰影效果
3. **懸停效果** - 卡片、按鈕、連結的懸停動畫
4. **進場動畫** - 元素進入視窗時的淡入與上升動畫
5. **計數器動畫** - 成就數字的動畫計數效果
6. **圖片放大** - 圖片懸停時的縮放效果
7. **返回頂部按鈕** - 捲動超過300px時出現
8. **主動導航連結** - 根據捲動位置高亮當前導航

## 📱 響應式設計

### 斷點設定
- **桌面** (>1200px)：完整佈局
- **平板** (768px - 1200px)：2列網格
- **手機** (480px - 768px)：1列網格，調整字體大小
- **小型手機** (<480px)：垂直佈局，最小化間距

## 🔧 自訂與維護

### 修改內容
1. 編輯 `index.html` 中的文字內容
2. 更新 `styles.css` 中的顏色、字體等樣式
3. 在 `script.js` 中新增或修改互動功能

### 新增圖片
1. 將圖片放入 `images/` 資料夾
2. 在 HTML 中使用 `<img src="images/檔名.jpg" alt="描述">`
3. 建議使用 JPG (照片) 或 PNG (圖表) 格式

### 新增課程或內容
1. 複製現有的課程卡片 HTML 結構
2. 修改文字與內容
3. 保持一致的 CSS 類別名稱
