入門

生成式 AI 的職場全方位應用

這是一堂讓 AI 成為你最強助理的必修課。從基礎的提示工程開始，深入探討如何利用 Manus 搜集資料、彙整資訊，並自動生成圖文並茂的簡報與網站。

適合對象： 職場人士、企業員工、AI 應用初學者
課程時長： 3 小時（講座）或 6~18 小時（工作坊）
預期成果： 掌握正確提問技巧，建立個人專屬的 AI 導入工作流，大幅提升工作效率

課程大綱：

  • 初探生成式 AI 與 Prompt Engineering
  • 向 AI 提問的 6 大心法
  • 透過 Manus 搜集與彙整資料
  • 生成圖文並茂的簡報與網站
  • 如何面對 AI 時代的變革
進階

全端開發實戰應用 - Vibe Coding

市場不會為爛產品買單！這堂課將帶領你體驗 AI Agent 的強大威力。從 Python 賦能、網路爬蟲，到將文件轉換為視覺化網頁，我們不僅教你快速啟動專案，更教你如何確保產品品質。

適合對象： 軟體開發人員、技術創業者、AI 輔助開發愛好者
課程時長： 3 小時（講座）或 6~12 小時（工作坊）
預期成果： 掌握 Vibe Coding 快速開發心法，能獨立完成具備穩定性的全端專案

課程大綱：

  • Manus 優勢與應用場景
  • Manus 基礎應用與 Markdown 概念
  • 設定規則獲得高品質回覆
  • AI Agent 初體驗與 Python 賦能
  • 版本控制與自動化測試
